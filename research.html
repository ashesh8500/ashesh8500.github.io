Research

Spatial memory from sparse visual observations

In progress. NYU WIRELESS, with Prof. Sundeep Rangan. 2026 to present.

An agent moving through a building should remember the physical objects it has seen. It needs to build that memory from a few views of each object, under noisy camera pose, without storing raw video.

Each new view is reduced to detected objects. A learned matcher decides, for each stored object, which new detection is the same object, or that none is. Matched observations update a bounded memory of objects and their spatial relations.

So far, I have evaluated identity matching and memory depth on simulated HM3D rooms. Testing on real indoor walkthrough video is still in progress, and a manuscript is in preparation. The code is private to the lab.

Agent interface for hardware design-space exploration

In progress. NYU WIRELESS, with Prof. Sundeep Rangan. September 2026 to present. Platform repository: sdrangan/waveflow.

The idea here is that a language-model agent should explore the design space of a hardware block the same way an engineer does, and cite evidence for the design it picks.

Waveflow is the lab's hardware design platform, where one Python description of a block drives simulation, high-level synthesis, and firmware. I built an agent interface that exposes a small set of tools over MCP and a command line: parameter discovery, Python simulation, resource prediction, synthesis, and RTL simulation. Results are stored by content, so a run can be replayed without the vendor toolchain.

Right now, the interface runs Python simulation on two blocks, a FIR filter and a memory copy, and replays recorded synthesis results for the FIR filter. Live synthesis in the agent loop and a comparison against grid search are next.

Planning with a frozen latent world model

In progress. Independent research. Fall 2026 to present.

A learned world model predicts how a scene changes under an action. I want to understand which representations and planner settings make good controls cheap to find, and why.

I keep the model (RoboJEPA) frozen and treat the system as separate modules: representation, predictor, objective, planner, and feedback. A cheap probe measures the action scale where the predictor can be trusted, and that scale sets the planner's search region. I compare sampling (CEM) and Gauss-Newton planners under one fixed scorer, writing down predictions before each run.

So far, I have run the baseline, the trust-region diagnosis, and a Gauss-Newton planner on development instances of a simulated reach task. Held-out confirmation and multi-step tasks are next.

Nicotine endorsement, impulsivity and brain structure in early adolescence

Complete. Honors thesis, UC San Diego, Department of Cognitive Science, 2025. Advisors: Mary Boyle and Rob Loughnan. Thesis (PDF).

Question

I wanted to test whether early nicotine use is linked to impulsivity, whether impulsivity predicts later nicotine use, and whether nicotine use shows up in brain structure.

Method

I used data from 9,562 participants in the Adolescent Brain Cognitive Development (ABCD) Study, about 9.9 years old at baseline. I tested behavioral links with generalized estimating equations to account for family clustering, and tested brain structure vertex by vertex with mixed-effects models.

Result

  • Baseline impulsivity raised the odds of starting nicotine within two years (odds ratios 1.56 to 1.78 across impulsivity measures).
  • No cortical or subcortical region survived correction for multiple comparisons. I report this as a null result.
