Research

Spatial memory from sparse visual observations

In progress. NYU WIRELESS, with Prof. Sundeep Rangan. 2026 to present.

An agent that moves through a building should remember the physical objects in it. The memory has to be built from a few views of each object, under noisy camera pose, without storing raw video.

Each new view is reduced to detected objects. A learned matcher decides, for each stored object, which detection shows the same object, or that none does. Matched observations update a bounded memory of objects and their spatial relations.

Identity matching and memory depth have been evaluated on simulated HM3D rooms. Work on real indoor walkthrough video is in progress, and a manuscript is in preparation. Code is private to the lab.

Agent interface for hardware design-space exploration

In progress. NYU WIRELESS, with Prof. Sundeep Rangan. September 2026 to present. Platform repository: sdrangan/waveflow.

A language-model agent should be able to explore the design space of a hardware block through the same steps an engineer uses, and cite evidence for the design it selects.

Waveflow is the lab's hardware design platform. One Python description of a block drives simulation, high-level synthesis and firmware. The agent interface exposes a small set of tools over MCP and a command line: parameter discovery, Python simulation, resource prediction, synthesis and RTL simulation. Results are stored by content, so a run can be replayed without the vendor toolchain.

The interface runs Python simulation on two blocks, a FIR filter and a memory copy, and replays recorded synthesis results for the FIR filter. Live synthesis in the agent loop and a comparison against grid search are next.

Planning with a frozen latent world model

In progress. Independent research. Fall 2026 to present.

A learned world model predicts how a scene changes under an action. The study asks which representations and planner settings make good controls cheap to find, and why.

The model (RoboJEPA) stays frozen. The system is treated as modules: representation, predictor, objective, planner and feedback. A cheap probe measures the action scale at which the predictor can be trusted, and that scale sets the planner's search region. Sampling (CEM) and Gauss-Newton planners are compared under one fixed scorer, with predictions written before each run.

The baseline, the trust-region diagnosis and a Gauss-Newton planner have been run on development instances of a simulated reach task. Held-out confirmation and multi-step tasks are next.

Nicotine endorsement, impulsivity and brain structure in early adolescence

Complete. Honors thesis, UC San Diego, Department of Cognitive Science, 2025. Advisors: Mary Boyle and Rob Loughnan. Thesis (PDF).

Question

Is early nicotine use linked to impulsivity, does impulsivity predict later nicotine use, and does nicotine use show in brain structure?

Method

The data are 9,562 participants of the Adolescent Brain Cognitive Development (ABCD) Study, about 9.9 years old at baseline. Behavioral links were tested with generalized estimating equations that account for family clustering. Brain structure was tested vertex by vertex with mixed-effects models.

Result

  • Baseline impulsivity raised the odds of starting nicotine within two years (odds ratios 1.56 to 1.78 across impulsivity measures).
  • No cortical or subcortical region survived correction for multiple comparisons. The thesis reports this as a null result.
