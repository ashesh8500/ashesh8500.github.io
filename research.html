Spatial memory from sparse visual observations

In progress. NYU WIRELESS, with Prof. Sundeep Rangan. 2026 to present. Code is private to the lab.

Question

An agent moves through a building and sees each object only a few times, from different viewpoints. When it detects an object, is this one it has seen before, or a new one? The agent must answer from runtime observations alone, with noisy camera pose and without keeping raw video.

Method

The matcher compares one stored object against every detected candidate in the new view, plus a "none" option. It uses visual, geometric and graph features that are available at runtime. Simulator identity labels are used only for training and scoring, never as runtime features.

The memory stores each object as a small set of accepted observations. Two policies are compared at one fixed decision threshold. K=1 keeps the latest observation per object. K=4 keeps up to four recent observations.

Result so far

Shuffled rows average 15 runs (3 checkpoints × 5 view orders). Chronological rows average 3 runs. Development room: 700 observations, 537 with evaluation labels, 72 physical objects. Unseen room: 700 observations, 585 with evaluation labels, 39 physical objects. Precision and recall score the decision to attach a new observation to an existing object. On the unseen room, the decision to attach an observation to an existing object is about 90% precise. Grouping observations into whole objects is harder: entity F1 is 41.7% with one observation per object and 52.8% with four, in shuffled order.

  • A manuscript is in preparation. Results on the real video are not public yet.

Agent interface for hardware design-space exploration

In progress. NYU WIRELESS, with Prof. Sundeep Rangan. September 2026 to present. Platform repository: sdrangan/waveflow.

Question

Waveflow is the lab's hardware design platform. One Python description of a block drives simulation, high-level synthesis and firmware. Can a language-model agent search the design space of a block through a small, fixed set of tools, and cite the evidence for its choice?

Method

The interface exposes a small set of tools over MCP and a command line: parameter discovery, Python simulation, resource prediction, synthesis and RTL simulation. Each call is content-addressed, so a repeated call returns the stored result. A replay mode answers synthesis queries from recorded HLS estimates, which lets the agent loop run on a machine without the vendor toolchain. A failed call returns as a data row.

Result so far

In a single recorded trial on a FIR filter block, the agent found the reference optimum (32 taps, 16-bit, serial architecture) in 20 tool calls and cited valid evidence for it. An earlier trial failed because oversized tool replies were cut off. Compact result views fixed that failure. Both trials are kept as regression fixtures.

Not yet done

  • The single successful trial shows the interface works end to end. It does not show that the agent outperforms grid search or a human designer.
  • Live synthesis and RTL runs inside the agent loop are not integrated yet.

Planning with a frozen latent world model

In progress. Independent research. Fall 2026 to present.

Question

A pretrained JEPA world model predicts the future in latent space. A planner searches for actions whose predicted outcome is close to a goal. How far can a planner trust the model's predictions, and can a cheap probe of that trust region set the planner's configuration?

Method

The model is RoboJEPA, kept frozen. The task is a simulated reach. Each experiment has a written prediction before it runs, a fixed scorer, and a second script that recomputes every count from the raw logs. The released sampling planner (CEM) is the baseline. Progress is the fraction of the initial distance to the goal that a run closes.

Result so far

All numbers come from 8 development instances with one planner seed.

  • The released CEM planner ends within 2 cm of the goal on 6 of 8 instances. On the 2 nearest starts it ends farther away than it began.
  • Capping each executed step at 5 cm makes progress positive on 8 of 8 instances. Mean progress rises from 0.59 to 0.89. The gain comes from the two failing instances, and the cap costs some progress on the other six.
  • A Gauss-Newton planner inside the same 5 cm region reaches mean progress 0.91. It plans in 1.3 s per step (median), against 211 s for CEM under the same cap.

By the fixed test, a paired bootstrap on median progress, no planner has beaten the baseline yet.

Not yet done

  • Held-out instances and more seeds.
  • Planning over a multi-step horizon.

Nicotine endorsement, impulsivity and brain structure in early adolescence

Complete. Honors thesis, UC San Diego, Department of Cognitive Science, 2025. Advisors: Mary Boyle and Rob Loughnan. Thesis (PDF).

Question

Is early nicotine use linked to impulsivity, does impulsivity predict later nicotine use, and does nicotine use show in brain structure?

Method

The data are 9,562 participants of the Adolescent Brain Cognitive Development (ABCD) Study, about 9.9 years old at baseline. Behavioral links were tested with generalized estimating equations that account for family clustering. Brain structure was tested vertex by vertex with mixed-effects models.

Result

  • Baseline impulsivity raised the odds of starting nicotine within two years (odds ratios 1.56 to 1.78 across impulsivity measures).
  • No cortical or subcortical region survived correction for multiple comparisons. The thesis reports this as a null result.
