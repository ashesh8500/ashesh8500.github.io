Spatial Intelligence

Runtime object association when the camera moves — and when the pose you trusted is wrong.

context NYU WIRELESS status research · in progress code private · not linked

The practical problem: keep object identity and association coherent as viewpoint changes. Clean pose is the easy case. Injected pose noise is the honest case. I treat them as separate evaluation stories so a single headline number can’t hide a brittle pipeline.

Source availability The implementation repository is private. There is no public GitHub link on purpose. These notes are the peer-into layer: problem framing, evaluation habits, and published metrics.

Public evaluation snapshot

strict-threshold F1 0.598 clean pose
strict-threshold F1 0.484 injected pose noise

Coverage and pseudo-label quality are reported separately from those F1 numbers. That split matters: a system can look strong on matched cases while quietly skipping hard ones, or while training on labels that aren’t as clean as the paper title implies.

How I think about the work

  • Visual, geometric, and relational cues all participate — none get to pretend they’re sufficient alone.
  • Leakage controls and ablations are part of the research, not afterthoughts.
  • Pose noise is a first-class condition, not a footnote.

What you won’t find here

Model weights, dataset dumps, private training configs, and the private repo. If you’re evaluating fit for collaboration, this page should tell you the research question and the standard of evidence — enough to start a conversation without publishing the lab notebook.
