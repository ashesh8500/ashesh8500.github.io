Ashesh Kaji

Ashesh Kaji is an MS student in Computer Engineering at NYU Tandon, graduating in December 2027. He does research at NYU WIRELESS with Prof. Sundeep Rangan. His BS with Honors is in Cognitive Science from UC San Diego, with a specialization in Machine Learning and Neural Computation.

The research asks how an agent can remember and act in a physical scene from limited observations. Two questions drive the current work. Which objects has the agent seen before? Which actions can a learned world model be trusted to plan?

He is looking for a research internship in machine learning for Summer 2027.

Current work

  • Spatial memory from sparse visual observations in progress
    Recognizing previously seen objects across viewpoints under a fixed memory budget. NYU WIRELESS.
  • Agent interface for hardware design-space exploration in progress
    Tools that let a language-model agent run simulation and synthesis queries in the Waveflow hardware design platform. NYU WIRELESS.
  • Planning with a frozen latent world model in progress
    A study of which planner settings a pretrained JEPA world model supports on a reach task. Independent.
