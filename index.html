Ashesh Kaji

I am an MS student in Computer Engineering at NYU Tandon, graduating in December 2027. I do research at NYU WIRELESS with Prof. Sundeep Rangan. Before NYU, I earned a BS with Honors in Cognitive Science at UC San Diego, specializing in Machine Learning and Neural Computation.

I love machine learning, the brain, and computers, and my undergraduate work in cognitive science is where my interest in learning systems comes from. Right now, I work on object memory for embodied agents and planning with learned world models.

Research in progress

  • Spatial memory from sparse visual observations
    Recognizing previously seen objects across viewpoints under a fixed memory budget. NYU WIRELESS.
  • Agent interface for hardware design-space exploration
    Tools that let a language-model agent run simulation and synthesis queries in the Waveflow hardware design platform. NYU WIRELESS.
  • Planning with a frozen latent world model
    A study of which planner settings a pretrained JEPA world model supports on a reach task. Independent.
