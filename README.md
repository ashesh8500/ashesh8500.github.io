# asheshkaji.com

Personal site of Ashesh Kaji. Static HTML and one stylesheet (`docs.css`). No build step and no scripts.

Pages: `index.html` (about), `research.html`, `projects.html`, `cv.html`. The resume PDF is `Ashesh_Kaji_Resume.pdf`.

Preview locally with `python3 -m http.server 8765` and open http://localhost:8765. GitHub Pages deploys from `main`.
